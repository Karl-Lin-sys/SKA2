# SKA2 - Curriculum Plan Guide Dashboard

This is the interactive portfolio dashboard for the **Curriculum Plan Guide (課程計畫引導師)** role at **Sunny Kids Academy**.

It demonstrates a scientific approach to pedagogy by blending Natural Language Processing (NLP) foundations with Learning Science (specifically Active Recall and Spaced Repetition) to maximize the educational efficacy of Mind Mapping (心智圖) while mitigating the "Illusion of Competence".

## Project Highlights
1. **Interactive Dashboard**: Modular single-page layout designed using premium vanilla CSS gradients, glassmorphism card modules, and fluid responsiveness.
2. **Active Recall / Retrieval Mapping Simulator**: Step-by-step interactive simulator explaining the "Recall ➔ Gap Check ➔ Spaced Repetition" workflow.
3. **Latest Research Integration**: Interactive charts contrasting the famous Karpicke & Blunt (2011) Science study against the 2023 replication/control studies.
4. **Interview Simulator**: Interactive Q&A typing terminal with expert pedagogical commentaries and strategic certificate alignment (Learning How to Learn for Youth, Mindshift).

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Karl-Lin-sys/SKA2.git
   cd SKA2
   ```
2. Open `index.html` directly in any modern browser, or run a local development server:
   ```bash
   npx live-server
   ```
